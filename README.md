# LocalAI — локальный десктоп-чат с GGUF моделями

Десктопное приложение на Python (PySide6) для запуска локальных LLM в формате
GGUF. Работает полностью офлайн: модель загружается и используется без
доступа в интернет. Поддерживается ускорение на GPU (NVIDIA CUDA) с
автоматическим переключением на CPU, если GPU недоступен.

---

## Возможности

- Загрузка любой `.gguf` модели через диалог выбора файла
- Чат с моделью, ответ выводится в реальном времени (стриминг токенов)
- Работа на GPU (CUDA) или CPU
- Полностью офлайн после установки — интернет не требуется

---

## Требования

- Windows 10/11
- Python 3.11+ ([скачать](https://www.python.org/downloads/))
- Файл модели в формате `.gguf` (например с [Hugging Face](https://huggingface.co/models?library=gguf))

Для ускорения на GPU дополнительно нужны:
- Видеокарта NVIDIA
- [CUDA Toolkit](https://developer.nvidia.com/cuda-downloads)
- [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (компонент "Desktop development with C++")
- [CMake](https://cmake.org/download/) (при установке отметить "Add CMake to system PATH")
- [Git](https://git-scm.com/downloads)

## Установка

### 1. Клонируй репозиторий и создай виртуальное окружение

```bash
git clone <ссылка-на-репозиторий>
cd practic_chat
python -m venv venv
venv\Scripts\activate
```

### 2. Установи зависимости

**Вариант B — только CPU (без видеокарты NVIDIA или для быстрого теста):**

```bash
pip install -r requirements.txt
pip install llama-cpp-python
```

### 3. Запусти приложение

```bash
python app.py
```

---

## Как пользоваться

1. Нажми **"Загрузить модель"** в боковой панели
2. Выбери `.gguf` файл модели
3. Дождись статуса **"Готово"** (индикатор в боковой панели)
4. Пиши сообщения в поле внизу, Enter — отправить, Shift+Enter — новая строка
5. **"Новый чат"** — очищает историю диалога

Приложение автоматически пробует использовать GPU. Если что-то пойдёт не
так — переключится на CPU без остановки работы (просто будет медленнее).

## Известные ограничения

- Поддерживаются только модели в формате `.gguf`
- Очень новые архитектуры моделей (например Qwen3-VL) могут быть
  несовместимы со старыми версиями `llama-cpp-python` — используйте
  проверенные модели (Llama 3.x, Qwen 2.x, Mistral и т.д.)
- История чата не сохраняется между запусками приложения (в разработке)
